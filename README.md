# Set the Bar

Visual aid for *115-1 Mastery Builder 2B-S11-1-3 — Distributions and Dot Plots*.

Open `index.html` in a browser (double-click) or publish the folder with GitHub Pages. No install or server needed.

- **Distributions:** dot plot (battery lifespans, 24 batteries), histogram (waiting times at Restaurant A and B, shown together), continuous curve (daily screen time of 1,000 junior-high students).
- **Forward — given *x*, find *p*:** drag the bar (it snaps to each grid point with a click); the app shows *n*(*X* ≥ *x*) and *P*(*X* ≥ *x*).
- **Reverse — given *p*, find *x*:** set a target *p*; the bar moves to the exact *x*, or to the closest one when *P*(*X* ≥ *x*) = *p* has no solution.
- Optional graph of *P*(*X* ≥ *x*) (tick "Show graph"), value table and practice questions with answers.

URL parameters (used for the worksheet screenshots in `screens/`):
`?dist=dot|hist|cont&mode=1|2&x=15&p=80&even=1&theme=light&shot=task,plot,readout,graph&nobar=1`
